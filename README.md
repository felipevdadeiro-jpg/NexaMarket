# NexaMarket

Marketplace de ativos digitais — estrutura inicial e interface visual, sem pagamentos reais.

## Como executar

1. Abra o arquivo `index.html` em um navegador.
2. Ou use um servidor local simples:

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Stack

- HTML
- CSS
- JavaScript

## O que foi incluído

- Hero section moderna
- Navegação e CTA
- Categorias de marketplace
- Cards de produtos em destaque
- Seção de benefícios
- Fluxo de compra em 3 etapas
- Layout responsivo
- Catálogo com filtros por categoria
- Página de detalhe do produto
